# Portfolio with JavaScript Interactivity

A responsive personal portfolio page extended with vanilla JavaScript: a validated contact form and a dark/light mode toggle.

## Features
- Contact form with validation (empty field checks + email format regex)
- Success message shown without page reload
- Dark mode / light mode toggle using classList.toggle()
- All interactivity handled via addEventListener (no inline onclick)

## How to run
1. Clone or download this repository
2. Open `index.html` in any web browser
3. No build steps or dependencies needed

## Built with
- HTML5
- CSS3 (Flexbox, transitions, dark mode styling)
- Vanilla JavaScript (DOM manipulation, form validation, events)

# Personal Portfolio Page

A simple, responsive one-page personal portfolio built with HTML and CSS.

## What it includes
- Header with name and title
- About Me section
- Skills section (styled with Flexbox)
- Contact section with email link

## How to run
1. Clone or download this repository
2. Open `index.html` in any web browser
3. No build steps or dependencies needed

## Built with
- HTML5
- CSS3 (Flexbox, media queries for responsiveness)
